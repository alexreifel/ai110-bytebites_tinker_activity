# ByteBites Reference File

## About This Project
You are building the backend logic for a campus food ordering app called ByteBites
using Python classes and simple algorithms.

## Project Scope
Do not add authentication logic, a database layer, or any features not described 
in the spec.

## Behavioral Instructions
- Stay within four classes: `Customer`, `MenuItem`, `Menu`, and `Order`. Don't add new
  classes, inheritance, or a central "system" class unless I ask.
- Keep it simple: standard-library Python only, plain lists and loops, no design
  patterns or external packages.
- Only build what the spec in `bytebites_spec.md` describes. If something seems missing
  (IDs, quantities, tax, etc.), point it out instead of adding it.
- Suggest changes in small steps: briefly say what and why first, then show the code.
- When something is ambiguous, ask before guessing.
